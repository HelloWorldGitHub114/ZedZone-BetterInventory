# Better Inventory / 更好的物品栏（收藏锁定 · 筛选分流 · 批量拖包）

《隔离区》（ZED ZONE）纯客户端物品栏与容器管理增强套件（BepInEx 6 IL2CPP，MIT 开源）。涵盖物品收藏防误操作、容器白/黑名单与三档拾取优先级自动分拣、以及框选多物品直接拖进闭合背包图标批量收纳三大核心功能。

- **前置依赖**：ZED ZONE Code Mod Loader（Steam Workshop ID: `3834614258`）
- **多人联机安全**：100% 纯客户端本地运行，单人与多人联机（房主未安装本模组）均可正常使用。

---

## 三大核心功能

### 1. 物品收藏锁定（防误丢 · 防误卖 · 防误存 · 防误拆）
- **一键标星**：背包内 `Alt + 左键` 或右键菜单切换收藏状态，物品图标左上角显示金色星标（独立于原版密码锁，持久化保存在存档与联机物品属性中）。
- **全方位误操作拦截**（各项均可独立开关）：
  - 免受附近储物箱**一键堆叠 / 存入同类**（含联机客户端一键堆叠）影响；
  - 免受容器**全部存入**影响；
  - 免受粉碎机**批量粉碎**影响；
  - 阻止**丢弃**（含右键丢弃、拖出丢弃与多选丢弃）；
  - 阻止**拆解**（含右键拆解与附近批量拆解）；
  - 在商人出售列表、批量出售扣减与交易拖拽中隐藏并保护已收藏物品；
  - 可选阻止 Shift/Ctrl 快速转移（默认关闭以便自由整理）。

### 2. 容器筛选与三档拾取优先级（自动分拣进包与箱子）
- **一键入口**：在主背包、储物箱与车辆容器标题栏，以及子背包/衣服口袋底栏左侧（紧邻原版快捷图标栏左侧空位，不挤压容器标题文字）自动添加紧凑规则按钮，右键背包图标也可直接打开，支持中英文双语自适应界面。
- **极简三档拾取顺序**：无需记忆复杂数字，直接点选 **`优先装入`** / **`正常`** / **`最后兜底`**，拾取战利品时按档位自动路由进主背包、衣服口袋及多层套包子包；同档位下命中过滤规则的专用容器优先于通用容器。
- **灵活多维度过滤**：
  - 支持**白名单（仅收勾选）**、**黑名单（排除勾选）**与**智能匹配（自动收容器内已有同款物品）**；
  - 支持按**物品大类**、**常用功能标签**（医疗/电池/燃料/门禁卡/开锁等）以及**一键导入当前容器内的精确物品**；
  - 一键堆叠与“全部存入”同步遵守目标箱子的过滤规则；可选开启手动拖拽严格过滤（按住 `LeftShift` 临时绕过）。

### 3. 框选多物品直接拖进背包图标（批量塞包）
- **补全原版操作盲区**：框选多个物品后，无需先点开目标背包窗口，直接拖放到主背包或储物箱内的闭合背包图标上即可批量收入包内。
- **安全护栏**：内置防套娃死循环校验（禁止将目标背包或其外层容器拖入自身）、自动避开密码锁背包、同步遵守手动严格过滤规则；空间不足时能放多少放多少，剩余物品安全弹回原格位，不丢件、不复制。

## 配置文件

首次启动游戏后自动生成：

```text
BepInEx/config/zedzone.betterinventory.cfg
```

无宿主物品的容器规则（主背包、储物箱）便携保存在 `BepInEx/config/BetterInventory.rules.txt`，卸载后不影响原版存档读取。

## 源码构建

```powershell
# 自动探测 Steam 中的 ZED ZONE 目录并构建打包到 content/BetterInventory
pwsh -NoProfile -File .\build.ps1

# 构建并安装到游戏 Mods 目录（需先关闭游戏）
pwsh -NoProfile -File .\build.ps1 -Install

# 手动指定游戏安装路径
pwsh -NoProfile -File .\build.ps1 -GameDir "<你的 ZED ZONE 安装路径>"
```
